# Rule corpus attribution

The detection rules in this directory are from **CodeGuard**, an open project
of the Coalition for Secure AI (CoSAI), originally released by Cisco.

- Source: https://github.com/cosai-oasis/project-codeguard
- License: Creative Commons Attribution 4.0 International (CC-BY-4.0)
  https://creativecommons.org/licenses/by/4.0/

Rules are used here unmodified as the Detector's rule corpus (Foundry spec
FR-041). The mapping from each rule to a CWE and the offline detection signals
live in `foundry/rules.py`, not in the rule files themselves.
